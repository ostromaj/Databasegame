# Who Wants to Be Rich? Database Edition

A game-show style review of database normalization (1NF, 2NF, 3NF).

- 15 questions on a money ladder from $100 to $1,000,000
- Difficulty climbs: questions 1–5 are warm-ups, 6–10 add composite keys and dependencies, 11–15 cover fixes, anomalies and sneaky cases
- Each game draws randomly from a bank of 31 questions, so replays differ
- Lifelines: 50:50, Ask the class, Phone a DBA (hint)
- Safe levels at $1,000 and $32,000, plus a walk-away option
- Keyboard: press A–D to pick, click Final answer (or pick the same letter again) to lock in

Play it at https://ostromaj.github.io/Databasegame/

To add questions, edit the `BANK` object near the top of the script in `index.html`. Questions in `easy`, `medium` and `hard` feed levels 1–5, 6–10 and 11–15.
